# Cutover plan

> Fictional office and people. Planning and approvals are case-study simulations; technical results are historical lab evidence only.

Proposed fictional office plan; not executed. Window: 18:00-20:00 Australia/Sydney on sponsor-approved working day. PC coordinates, IT operates, SP decides, SO reviews exposure. Notice 48h before. Real application requires approved design and recovery rehearsal.

| Relative time | Owner | Action | Exit / evidence |
|---|---|---|---|
| T-2 days | PC | Confirm prerequisites, access matrix, roster, notice | Real-office gate approved |
| T-60 min | IT | Freeze changes and capture baseline | Version and inventory |
| T-45 min | IT | Consistent volume backup, encrypted config/credential copy | Manifest; rehearsal already passed |
| T+0 | SP / IT | Go/no-go; apply approved config | Decision/operator recorded |
| T+20 | IT | Services / directory health | No failures |
| T+40 | IT / FM | Public positive, Finance positive/negative | User-specific proof |
| T+60 | IT / UR | Tunnel plus files and physical print | End-to-end acceptance |
| T+80 | PC / SO | Review revocation, monitors, deviations | No Critical/High defects |
| T+90 | SP | Accept or order rollback | Decision before window end |
| T+1 day | IT / PC | Hypercare triage and daily checks | Owned actions |

Stop: unintended access, failed core service, unverified backup, High defect. If recovery cannot complete by T+90, SP orders rollback. SO may order immediate isolation for exposure. Use rollback plan. Lab commands are upstream; this pack does not execute them.
